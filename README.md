# CIE 2 – Activity 1: Regression

## Objective
To implement Simple and Multiple Linear Regression using a suitable dataset and evaluate the performance of the regression models.

## Dataset
**Dataset Name:** Diabetes Dataset  
**Source:** Scikit-learn  
**Dataset:** Built-in Diabetes dataset from `sklearn.datasets`

## Features Used
- BMI
- Blood Pressure (BP)
- S5

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Statsmodels

## Activities Performed
- Loaded and explored the Diabetes dataset.
- Checked dataset information, missing values, duplicates, and statistical summary.
- Performed data visualization using scatter plots and a correlation heatmap.
- Created a design matrix and calculated regression coefficients manually.
- Implemented Simple Linear Regression.
- Implemented Multiple Linear Regression.
- Evaluated models using MAE, MSE, RMSE, R², and Adjusted R².
- Visualized residuals and actual versus predicted values.
- Calculated Variance Inflation Factor (VIF).
- Predicted a new value using the trained model.

## Conclusion
Simple and Multiple Linear Regression models were implemented successfully. Their performance was evaluated using regression metrics and visualizations.
